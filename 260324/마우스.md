# 🖱️ 마우스 클릭 방식 정리 (기계식 vs 광학/햅틱)

## 1. 개요

최근 게이밍 마우스(예: 로지텍 G Pro X Superlight 2 등)에서는  
기존 기계식 스위치 대신 **광학(Optical) + 햅틱 구조**가 사용되고 있다.

본 문서는 다음 내용을 정리한다:

- 마우스 클릭 방식의 정의
- 기존 기계식 스위치 동작 원리
- 광학/햅틱 방식 동작 원리
- 두 방식의 차이점

---

## 2. 클릭 방식 정의

### 2.1 기계식 스위치 (Mechanical Switch)
<img width="1600" height="1600" alt="image" src="https://github.com/user-attachments/assets/0a784788-da86-488a-9d62-d4d1cee41111" />

- 금속 접점을 이용하여 클릭을 감지
- 물리적인 접촉 기반 입력 방식

---

### 2.2 광학 스위치 (Optical Switch)

- 적외선(빛)을 이용하여 클릭을 감지
- 물리 접점 없이 입력 처리

---

### 2.3 햅틱 피드백 (Haptic Feedback)

- 실제 클릭 느낌을 사용자에게 전달하기 위한 기술
- 진동 또는 스프링 구조로 클릭감 구현

> 최신 마우스는  
> **입력 감지 = 광학 / 클릭 느낌 = 기계 or 햅틱**  
> 구조로 분리되는 경우가 많다.

---

## 3. 기계식 스위치 동작 원리

### 구조

- 버튼 (플라스틱)
- 스프링
- 금속 접점

---

### 동작 과정

1. 버튼을 누름
2. 내부 스프링이 휘어짐
3. 금속 접점이 서로 닿음
4. 전기 신호 ON → 클릭 인식

---

### 특징

- ✔️ 명확한 클릭감 (딸깍)
- ❌ 접점 마모 발생
- ❌ 더블클릭 오류 발생 가능
- ❌ 디바운스 처리 필요 (지연 발생)
- ❌ 수명 제한 존재

---

## 4. 광학/햅틱 방식 동작 원리

---

### 4.1 광학 스위치 (입력 감지)

### 구조

- 적외선 LED
- 광 센서

---

### 동작 과정

1. 기본 상태: 빛이 계속 통과
2. 버튼을 누르면 구조물이 빛을 차단
3. 센서가 빛 끊김 감지
4. 클릭 신호 발생

---

### 핵심 특징

- 물리 접점 없음
- 빛으로 입력 판단

---

### 4.2 햅틱 / 클릭감 구현

광학 스위치는 "입력 감지"만 수행하기 때문에  
클릭 느낌은 별도로 구현해야 한다.

---

#### 방식 1. 기계식 클릭감 유지

- 스프링 구조 유지
- 클릭 느낌은 기계식과 유사
- 입력 신호는 광학 방식 사용

---

#### 방식 2. 진동 기반 햅틱

- 진동 모터 사용
- 클릭 느낌을 인위적으로 생성
- (주로 트랙패드에서 사용)

---

## 5. 기계식 vs 광학/햅틱 비교

| 구분 | 기계식 스위치 | 광학/햅틱 |
|------|--------------|-----------|
| 입력 방식 | 금속 접점 | 빛 (적외선) |
| 반응 속도 | 디바운스 필요 | 즉시 반응 |
| 내구성 | 접점 마모 존재 | 마모 거의 없음 |
| 더블클릭 오류 | 발생 가능 | 거의 없음 |
| 클릭감 | 자연스러움 | 설계에 따라 다름 |
| 구조 | 단순 | 비교적 복잡 |
| 게이밍 적합성 | 보통 | 매우 높음 |

---

## 6. 핵심 차이 요약

- 기계식  
  → "눌러서 전기가 통하면 클릭"

- 광학  
  → "눌러서 빛이 끊기면 클릭"

- 햅틱  
  → "클릭 느낌은 따로 만들어준다"

---

## 7. 게이밍 환경에서의 장점

광학 방식이 선호되는 이유:

- ⚡ 입력 지연 최소화
- 🔥 더블클릭 문제 감소
- 🧱 높은 내구성
- 🎯 일정한 클릭 성능 유지

---

## 8. 결론

기존 기계식 스위치는 단순하고 직관적인 구조를 가지지만,  
마모와 입력 지연이라는 한계가 존재한다.

광학/햅틱 방식은  
입력과 클릭감을 분리하여 설계함으로써

- 성능
- 내구성
- 안정성

을 모두 개선한 구조라고 볼 수 있다.
