## 1. 한미 FTA 공동위원회란?
- **역할**: 관세협상 팩트시트의 **비관세 분야 합의 내용**의 구체적 이행 방안 마련
- **예정 일시**: 2025년 12월 18-19일 (현지시간)
- **현황**: 2026년 1월 초로 **연기됨**

### 왜 이 회의가 중요한가?
팩트시트에 담긴 비관세 분야 합의 내용이 실제로 **법적 효력**을 가지려면 FTA 공동위원회에서 공식 합의되고 명문화되어야 합니다.

- ✅ 합의 성공 → 합의된 관세율 발효 + 비관세 장벽 완화
- ❌ 합의 실패 → 여전히 **고관세 유지** + 비관세 장벽 존속

---

## 2. 회의 취소의 배경: 온라인플랫폼법(온플법)

### A. 표면적 이유 vs 실제 원인

#### 표면적 이유
- "디지털 정책에 대한 견해 차이"
- "의제 조율에 추가 시간 필요"

#### 실제 원인: 온라인플랫폼법 재추진
한국 민주당이 12월 초 **온라인플랫폼법**을 국회에 재시동하면서 미국의 즉각적 반발을 초래

### B. 온라인플랫폼법이란?

| 항목 | 내용 |
|------|------|
| **규제 대상** | 쿠팡, 네이버 쇼핑, 카카오톡 등 지배적 온라인 플랫폼 |
| **핵심 규제** | 자사 상품 우대, 판매자 차별 금지 |
| **과징금** | 매출액의 최대 10% (거래공정화법 개정) |
| **배경** | 쿠팡 등 대형 플랫폼의 부당 대우 근절 |
| **미국의 입장** | "미국 기업(쿠팡=미국 기반, 아마존 경쟁사) 차별" |

### C. 한미 팩트시트와의 충돌

**팩트시트의 디지털 약속** (11월 14일)
> <mark>한국과 미국은 망 사용료, 온라인플랫폼 규제를 포함한 
디지털 서비스 관련 법과 정책에 있어서 미국 기업들이 
차별당하거나 불필요한 장벽에 직면하지 않도록 
보장할 것을 약속한다.</mark>

**해석의 차이**:
- **한국**: "새로운 차별만 금지, 기존 규제는 유지 가능"
- **미국**: "새로운 규제 법안 발의 자체가 금지"

**결과**: 온플법 재추진 → 미국의 반발 → FTA 공동위 연기

## 3. 쿠팡 해킹 사태와의 연관성

### 타이밍 분석

| 일자 | 사건 |
|------|------|
| **11월 14일** | 한미 정상회담 (팩트시트 합의) |
| **12월 초** | 쿠팡 대규모 해킹 사태 발생 (520만 고객 개인정보 유출) |
| **12월 초** | 민주당, 온플법·거래공정화법 재시동 |
| **12월 18-19일** | FTA 공동위 **돌연 취소** |

### 한국의 명분

- 쿠팡 해킹 사태로 인한 **국민 불만 해소** 필요
- 온플법을 통한 **대형 플랫폼 규제 강화** 필요
- 비관세협상이 마무리되면 추진 의사 (사후 처리)

### 미국의 반발

- "팩트시트 위반"으로 간주
- 온플법 = 쿠팡(미국 기업) 때리기로 해석
- FTA 공동위 연기로 **협상 압박**

## 5. 공동위 연기의 영향

### A. 기업 입장: 발효 지연

**제네릭·천연자원 면제는 이미 합의되었으나, 공동위 개최 연기로 발효가 지연됨**

| 분야 | 원래 예정 | 현재 예정 | 지연 기간 |
|------|---------|---------|---------|
| 제네릭 의약품 발효 | 12월 | 1월~2월 | 1~2개월 |
| 천연자원 발효 | 12월 | 1월~2월 | 1~2개월 |
| 반도체 협상 | 12월 | 1월 | 1개월 |

### B. 국가 입장: 협상력 악화

**미국이 공동위 연기로 협상 압박 강화 중**

- 온플법 철회/완화 → 공동위 개최
- 온플법 강행 → 추가 관세 인상 가능성

## 6. 온플법 재추진의 함정

### 현재 상황

```
쿠팡 해킹 사태 (12월 초)
    ↓
민주당: "국민 불만 해소, 온플법 추진해야 함"
    ↓
미국: "FTA 공동위 취소 (보복)"
    ↓
한국 정부: "비관세 협상 마친 후 추진하겠다" (사후 처리)
```

### 위험성

| 위험 요소 | 설명 |
|---------|------|
| **협상 재개 불확실성** | 미국이 온플법 철회를 조건으로 제시할 수 있음 |
| **관세 인상 가능성** | 미국이 "비관세 미이행" 이유로 추가 관세 부과 가능 |
| **투자 약속 미납** | 미국이 3,500억 달러 투자 정체 가능성 언급 가능 |
| **입법 자유도 제약** | 한국의 자체 입법이 미국 무역 협상의 대상화됨 |

## 7. 핵심 질문과 답변

### Q1: 공동위가 없으면 어떻게 되나?
```
✗ 공동위 합의 전까지: 여전히 고관세 유지
✓ 공동위 합의 후: 합의된 관세율 인하 발효
```

### Q2: 온플법 때문에 공동위가 취소된 건가?
```
✓ 맞음. 하지만 직접 취소라기보다는 "압박 신호"
미국: "온플법 철회 없으면 공동위 안 함"
한국: "비관세협상 우선 마친 후 온플법 추진"
```

### Q3: 쿠팡 규제는 왜 문제가 되나?
```
쿠팡 = 아마존 모델을 한국에서 시도하는 미국 기업
온플법 = 쿠팡의 부당 대우 금지 규제

미국 입장: "한국이 미국 기업만 때리는 건 FTA 위반"
한국 입장: "차별 아니라, 모든 플랫폼에 적용되는 규제"
```

### Q4: 결국 어떻게 될까?
```
**시나리오 1 (가능성 높음)**: 
온플법 기존 내용 유지 + 비관세협상 완료 + 관세 발효
(미국이 온플법을 "비차별"이라고 해석하면 가능)

**시나리오 2 (가능성 낮음)**:
온플법 완화 + 공동위 개최 + 추가 관세 인하
(미국의 강경 입장)

**시나리오 3 (최악)**:
온플법 철회 + 공동위 지연 + 관세 재협상
(협상 결렬 경우)
```

## 9. 결론: 온플법 vs 비관세협상의 줄다리기

### 현재 상황
```
한국의 선택지:
1️⃣ 온플법 강행 → 미국 강경 대응 → 관세 재협상 위험
2️⃣ 온플법 유보 → 공동위 개최 → 관세 발효 + 투자 진행
3️⃣ 온플법 완화 → 미국과 타협 → 비차별 조건 충족
```

### 한국 정부의 공식 입장
- "비관세협상을 먼저 마무리하겠다"
- "협상 후 온플법 추진 여부 재검토"

### 미국의 입장
- "온플법은 미국 기업 차별"
- "팩트시트의 비차별 원칙 위반"

### 예상 결과
**2026년 1월 FTA 공동위 개최 → 온플법의 "비차별성" 재논쟁 → 타협안 모색**
