## 1. 플레오스 커넥트란?

플레오스 커넥트(Pleos Connect)는 현대차의 차세대 차량 운영체제(OS) 플랫폼

- 차량용 OS
- AI 비서
- 앱 생태계

더 뉴 그랜저에 최초 본격 적용되며 현대차 SDV 전략의 시작점으로 평가받고 있음.

# 2. 주요 기능

## 2-1. 17인치 통합 디스플레이

기존 차량처럼:
- 계기판
- 내비게이션
- 공조

가 각각 분리된 구조가 아니라,

하나의 대형 디스플레이에서:
- 속도 정보
- 내비게이션
- 음악
- 차량 설정
- 앱 실행

등을 통합 제어

즉 차량을 스마트폰/태블릿처럼 사용하는 방향

---

## 2-2. 생성형 AI 비서 “글레오 AI(Gleo AI)”

LLM 기반 생성형 AI 비서가 탑재된다.

예시:
- “에어컨 끄고 무드등 숲 느낌으로 바꿔줘”
- “운전석 통풍시트 켜줘”
- “근처 조용한 카페 추천해줘”

---

## 2-3. 차량 앱스토어 / 앱 생태계

AAOS(Android Automotive OS) 기반으로 동작한다.

즉 스마트폰 연결 없이 차량 자체에서:
- 내비
- 음악
- OTT
- 웹검색
- 게임

등의 앱을 실행할 수 있음.

# 3. 테슬라와 차이점

| 항목 | 현대 플레오스 커넥트 | Tesla |
|---|---|---|
| 운영체제 | AAOS 기반 | 자체 OS |
| 앱 생태계 | 안드로이드 친화 | 폐쇄형 |
| 음성 AI | 생성형 AI 강화 | 비교적 단순 |
| UX 철학 | 기존 자동차 UX 유지 | 화면 중심 극단 통합 |
| 물리 버튼 | 일부 유지 | 최소화 |

# 4. 자율주행도 가능한가?

현재는 “완전 자율주행 플랫폼”이라기보다는
자율주행을 위한 기반 OS에 가까움
+ 이번에 나온 그랜저의 플레오스는 걍 인포테이먼트 시스템임

“향후 AI 자율주행을 얹기 위한 차량 컴퓨팅 플랫폼”
