# 왜 무선 모니터는 없는가?

데스크탑 환경을 보면 대부분의 주변기기는 이미 무선화되었다.

- 무선 마우스 → Bluetooth / 2.4GHz 리시버  
- 무선 키보드 → 동일 방식  
- 네트워크 → Wi-Fi / 무선 LAN  
- 스피커·헤드셋도 무선화 완료  

하지만 유독 **모니터만큼은 HDMI, DisplayPort 같은 케이블 연결이 일반적**이다.  
화면 미러링이나 캐스팅 기술은 존재하지만 완전한 “무선 모니터”라고 보긴 어렵다.

그 이유를 기술적·실용적 관점에서 정리해보자.

---

## 1️⃣ 4K가 아니어도 무선 모니터가 흔하지 않은 이유

해상도를 낮추면 데이터량은 줄어든다.

| 해상도 | 필요 대역폭(대략) |
|--------|----------------|
| 4K 60Hz | 수 Gbps 이상 |
| QHD | 약 2~4Gbps |
| FHD | 약 1~3Gbps |
| HD | 수백 Mbps |

즉 FHD 정도라면 최신 Wi-Fi 기술로 전송 가능하다.

실제로 이미 존재:

- TV 화면 캐스팅  
- 회의실 무선 프레젠테이션  
- 무선 HDMI 동글  

하지만 데스크탑 모니터에서는 여전히 유선이 주류다.

---

## 2️⃣ 기술적으로 불가능한가?

결론:

👉 **불가능하지 않다. 이미 기술은 존재한다.**

대표 기술:

- Miracast  
- AirPlay  
- Wireless HDMI  
- WiGig(mmWave 기반 초고속 무선)

하지만 몇 가지 기술적 문제가 존재한다.

### ✔️ 지연(Latency)

영상 무선 전송 과정:

1. 화면 캡처  
2. 압축 인코딩  
3. 무선 전송  
4. 복호화 출력  

이 과정에서 지연 발생:

- 게임 반응 속도 저하  
- 마우스 움직임 딜레이  
- 개발 환경에서 타이핑 체감 저하  

해상도를 낮춰도 완전히 해결되지는 않는다.

---

### ✔️ 압축 화질 문제

영상 감상은 괜찮지만:

- 코드 에디터 텍스트  
- 디자인 작업  
- 문서 작업  

에서는 압축 artifact가 눈에 띈다.

특히 개발자 환경에서는 치명적이다.

---

### ✔️ 안정성 문제

유선:

- 거의 지연 없음  
- 끊김 없음  
- 환경 영향 적음  

무선:

- 전파 간섭 영향 큼  
- 네트워크 상태 영향 받음  
- 끊김 발생 가능  

업무 환경에서는 안정성이 중요하다.

---

## 3️⃣ 상용화가 어려운 이유

### ✔️ 비용 대비 효용

고품질 무선 영상 장비:

- 수십만~수백만원 수준

하지만 HDMI 케이블:

👉 몇 천원 수준.

즉 시장성이 제한적이다.

---

### ✔️ 전원 케이블 문제

모니터는 전력 소비가 크다.

그래서:

👉 전원 케이블은 어차피 필요.

결국 영상 케이블 하나 줄이는 정도라 체감 이점이 작다.

---

## 4️⃣ 왜 노트북 → 무선 모니터는 상대적으로 쉬운가?

핵심은 사용 환경 차이다.

### ✔️ 사용 목적 차이

노트북:

- 영상 감상  
- 프레젠테이션  
- 간단 작업  

👉 약간의 지연 허용 가능.

데스크탑:

- 개발 작업  
- 게임  
- 그래픽 작업  

👉 지연 거의 허용 안 됨.

---

### ✔️ 설계 구조 차이

노트북:

- Wi-Fi 기본 내장  
- 이동성 중심 설계  
- 화면 공유 기능 기본 제공

데스크탑:

- GPU 직접 출력 중심  
- 성능·안정성 우선 설계

---

### ✔️ 기대 수준 차이

노트북 무선 화면:

👉 편의성 중심.

데스크탑 모니터:

👉 완벽한 반응성과 화질 요구.

이 기대치 차이가 시장 형성에도 영향 준다.

---

## 🎯 결론

기술적으로는 가능하다.

하지만 현실적으로:

1. 지연 문제  
2. 압축 화질 저하  
3. 비용 대비 효용 낮음  
4. 전원 케이블 필수  
5. 유선 안정성 우수  

그래서 현재까지는:

👉 완전 무선 모니터는 틈새 제품 수준에 머무르고 있다.

---

## 💡 미래 전망

가능성이 열리는 조건:

- 초고속 저지연 무선 기술 발전  
- 압축 기술 개선  
- XR/가상 디스플레이 확산  
- GPU 무선 출력 표준화  

그때는 케이블 없는 데스크 환경도 현실이 될 수 있다.
